    state "WLAN_INIT: wlan_est() -> net.init()" as WLAN_INIT

    state "WAIT_NETWORK: wait up to 30s for connection" as WAIT_NETWORK
    WAIT_NETWORK --> NTP_SYNC: connected
    WAIT_NETWORK --> NETWORK_FAIL: timeout

    state "NTP_SYNC: ntptime.settime() (if wlan_mode==0)" as NTP_SYNC

    state "NETWORK_OK: wlan_init = is_connected()" as NETWORK_OK
    state "NETWORK_FAIL: wlan_init = False" as NETWORK_FAIL

    NETWORK_OK --> AP_MODE: wlan_mode==1 and not wlan_init

    NETWORK_OK --> IDLE: no network

Пояснения

Состояния — этапы работы устройства (инициализация, ожидание сети, работа с HUB и т.д.).
Переходы — условия перехода между состояниями.
AP_MODE — режим точки доступа для настройки через веб-интерфейс (блокирующий).
WEBAPP_THREAD — веб-интерфейс запускается в отдельном потоке.
PC_SIM — ветка для запуска на ПК (симуляция, без MicroPython).
RESET — перезагрузка устройства при потере соединения с HUB.
