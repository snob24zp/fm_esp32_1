# Цикл программирования и отладки ESP32

## 1. Запись изменений на ESP32

Для записи файлов используется скрипт:

```powershell
.\flash_p2.ps1 COM4
```

где **COM4** — номер COM-порта, к которому подключена ESP32. При необходимости замените его на свой (например, `COM3`, `COM5` и т.д.).

По умолчанию `flash_p2.ps1` записывает **только изменённые файлы**, что значительно ускоряет цикл разработки.

Если требуется полностью переписать все файлы на устройстве, используйте параметр:

```powershell
.\flash_p2.ps1 COM4 -force
```

После завершения записи дождитесь автоматического запуска ESP32.

---

## 2. Автономная проверка

Проверить работу ESP32 без использования Thonny:

1. Подключиться к точке доступа ESP32.
2. Открыть Web-интерфейс ESP32 в браузере.
3. Проверить работу необходимых функций.

Для диагностики Web-интерфейса рекомендуется использовать браузер на компьютере.

Откройте **Developer Tools (F12)**:

- **Console** — ошибки JavaScript.
- **Network** — HTTP-запросы к ESP32 и ответы.
- **Response** — содержимое ответа ESP32.

---

## 3. Просмотр логов через Thonny

Этот этап не зависит от автономной проверки и может использоваться сразу после прошивки.

1. Подключить ESP32 по USB.
2. Запустить Thonny.
3. Выбрать интерпретатор **MicroPython (ESP32)** и нужный COM-порт.
4. Открыть **Shell**.

Если ESP32 уже выполняет программу, **не нажимать Stop или Run**.

В Shell отображаются сообщения `print()` и диагностические логи работающей программы.

---

## 4. Интерактивная отладка

Если необходимо выполнить диагностику вручную:

1. Нажать **Stop**.
2. Дождаться появления приглашения:

```text
>>>
```

3. Выполнять команды через REPL, например:

```python
import board
import gc

board.network.is_connected()
board.network.ifconfig()
board.network.scan()

gc.collect()
gc.mem_free()
```

При необходимости открыть изменённый `.py`-файл и запустить его через **Run (F5)**.
