# Topic 'error'

## Types of error

| Error number | Definition |
| ---- | ---- |
| 1 | Counted send events is not the same as server received, device should make registration again |
| 2 | Block device (server will ignore messages from device) |
| 3 | Server wants that device send all non zero registers, to update current device status on server |
| 4 | Disable events engine in device, events topics of device will be handled by server |
