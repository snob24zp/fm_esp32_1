# Topic version

Topic version gives ability to read current version of uclient. 

To get version string need to send word 'version' into `/{HUB}/version` topic

Example:

```
[1698837138] >48:3f:da:55:07:5b/version version  
[1698837139] <48:3f:da:55:07:5b/version R231029;master;123c320d946ceeb854084f2ee1b9bf26a2b9cfad
```
